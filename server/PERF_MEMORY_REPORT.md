### 残存割り当てとコード上の候補

- 割り当てプロファイルには、履歴正規化の `side()` 起点の板レベルオブジェクトが残っているサンプルがあった。ただし、取り込み中に必要な保持と、不必要な保持・リークの区別は未完了。
