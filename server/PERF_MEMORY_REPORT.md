### 今回の停止確認と保留

PID12722は17:24:33.465 JSTにSIGTERM、17:24:33.736に実上流close1006・socketClosed、17:24:33.760にpeer1終了、17:24:33.766にHTTP終了を確認した。現在はAPI・画面workflowを停止している。

公開プレビューURLをoriginとする接続を一時的に拒否して計測用のローカル接続だけに制限すれば、条件を固定できる可能性がある。ただし既存の接続可否を変えるため、まだ実装せず許可待ち。許可された場合も、拒否した接続はログに残し、拒否によって0にしたことと、ブラウザ自体を停止したことを区別して報告する。保存データ・配信形式・Run設定は変えない方針。
