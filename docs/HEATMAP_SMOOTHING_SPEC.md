# HEATMAP 表示専用平均化・平滑化

2026-10-30ユーザー承認。従来の縮小時最大値の案に代わる。

- NQ／GCの板背景のみ。初期値は時間「平均」、価格「自動」。既存設定画面の「表示（このタブ）」に追加し、銘柄別sessionStorageで保持。設定PUT・version・保存済み色設定は変更しない。
- 1秒代表列の元数量を画素との重なり時間で重み付けする。「最大」も選択できる。多段処理では数量×有効時間の合計と有効時間を足す。秒内イベントの時間平均ではない。
- 価格「自動」は複数ティックが物理画素へ縮小されるときに価格帯の重なり面積と時間有効重みで平均する。「なし」は最大。拡大時は元ティック値。DPRを含む物理画素で計算する。
- 元数量→時間集約→価格集約→既存上下限・gamma→色→block／glow装飾。RGB補間や追加の全画面ぼかしは使わない。
- 明示された0は既知。欠落行・範囲外・取得されない列はunknown。全unknownは描かず、一部unknownは有効面積率で減衰する。欠損へglowを漏らさない。表示補間を実測平均・自動色基準へ含めない。平均化経路は欠損を補間描画しない。
- 自動色基準は従来の実測の正の1秒×価格セルから計算する。集約後の画素分布を使わない。
- 保存列・約定・数量集計・現在板・FOOTPRINT・LONG VP・CVD／VWAPを変更しない。履歴の品質を完全へ昇格しない。
- 派生列キャッシュは既存表示と同じ2時間の時間範囲制限・48MiBの配列容量制限を使用。列の参照変更と描画幾何が変わった範囲を再計算する。カーソル層・最新約定の更新優先順・非表示停止は既存を維持する。
