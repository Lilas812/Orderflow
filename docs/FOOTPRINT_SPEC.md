# FOOTPRINT 初期仕様

2026-10-30：ユーザーの専用画面追加指示を関係箇所だけ反映。全文仕様差替えではない。

## 1. 画面・操作

- 同じアプリにHEATMAP／FOOTPRINT／LONG VPの3タブ。FOOTPRINTは専用画面で、他画面への重ね表示ではない。
- NQ・標準GC、既存の確認済みtickSize・価格桁数を使う。共通ヘッダーの銘柄と既存サーバー設定の時刻表示を共有。各画面の閲覧位置・ズーム・追従は独立。
- 足種5秒・15秒・30秒・1分、初期5秒。そのブラウザタブのsessionStorageだけに保持。サーバー設定の追加なし。
- 暗い背景、価格1ティックごとの左右2セル。左sell／右buyの枚数、薄い灰色を基本とし、同価格でbuy優勢なら右を緑、sell優勢なら左を紫、同数は両方灰色。凡例を設ける。比率・最小数量閾値やimbalance名称は追加しない。
- 細いOHLC足、右価格軸、下時間軸、足ごとの総出来高・デルタ、足内POCの細枠を表示。POCはbuy＋sell最大行、同数なら高価格。無約定にOHLC／POCを生成しない。
- 数字を読める大きさで表示。縮小時は重複数字を非表示にしてOHLC等の概要へ移行し、数量は捨てない。価格行の結合なし。
- 既存に合わせたパン・ズーム・追従・表示リセット・独立十字カーソル。カーソルの価格・時刻は当画面の座標を使い、領域外・切替時に消す。
- glow、diagonal／stacked imbalance、売買シグナル、参考製品ロゴ・周辺ツールは対象外。

## 2. 集計・整合性

- 入力は既存正規化約定。バブル閾値・間引きより前の全約定を用い、板・1分足・LONG VPから逆算しない。
- 基礎ドメインは銘柄・限月・1秒・整数価格ティックごとのbuy／sell枚数。最初／最後の約定情報も持ち、選択足に合算する。
- 内部時刻は整数Unixマイクロ秒、足は取引時刻の半開区間[start,end)。タイムゾーンは表示だけ。総出来高=buy＋sell、デルタ=buy−sell。
- 同時刻・同価格・同枚数でも正当な別約定を保持。同時刻の先後は既存の入力順序で、厳密な秒内取引所順序を復元したとはしない。
- 遅着・履歴置換・ライブ重複・再接続・サーバー世代変更で影響範囲を更新。履歴は単純加算しない。seqは世代を超える永続IDではない。旧要求・旧銘柄の遅延応答を破棄する。
- 異なる既知限月を別系列・別足とし混ぜない。GCの限月不明を明示し、現在限月を過去へ適用したり推測の価格調整をしない。
- 形成中／時間終了と、取得中／読込済み記録／既知の未取得区間を分離。未取得を0枚としない。受信済み数量と不完全な足の印を表示する。時間終了・coverageだけで市場データの完全性を保証しない。
- 確認済み無約定と失敗を分離する。後着履歴は数量と状態を一緒に置換し、閲覧位置を変えない。

## 3. 取得・配信・保存

- 既存上流1接続・NQ／GCの収集保存・下流WSを共用。専用上流・VM・DB・原約定の複製保存なし。
- `GET /api/ws?view=footprint&symbol=NQ|GC`のUpgradeで同じHubへ接続。従来クライアントの契約は維持する。
- FOOTPRINT向けhelloだけにHub世代UUIDを追加。自動30分初期読取、下流板フレーム、VP配信はしない。表示範囲だけを既存`op:range`要求（1件最大3600秒）で読む。
- 約定は既存`rangeTrades`／`trades` JSON（任意contract含む）。`rangeDone`に`footprint`取得状況を追加：`coverage`は取得記録の半開区間、`gaps`は未記録範囲、`noData`は確認済み無約定の情報、`quality`は`recorded_not_guaranteed`。従来画面への追加なし。
- 既存storeの`tradeReadSession`を使用。書込前ライブtailを含め、同じ受信identityだけを現世代内で除重。追加REST取込は開始せず既存背景backfill・履歴鮮度通知・明示再試行を共用する。未取得はそのまま表示する。
- 閲覧対象は最新から2時間。最初から全2時間を取得せず可視範囲だけ、取得済み範囲は再利用。毎秒の履歴再要求をしない。
- データ更新の本体描画は最大毎秒1回、操作・カーソルはrAF。非表示時は描画・不要な集計を停止し、復帰時に最新へ追いつく。
- 集計の時間・容量上限、溢れ時の明示、解放方法・実測は実装報告書へ記載する。不要な足種・銘柄キャッシュを累積させない。
- バッチは最大512約定で送る。同期visitor中に送信待ちが16MiBを超えたら未完要求をエラーとし、成功coverageを返さない。巨大な未送信Promise列を保持しない。
- HEATMAPの色・板・バブル・設定、LONG VPの集計表示、保存形式・保持期間・期限削除は変更しない。

## 4. 検証

既知入力の価格別buy／sell、総量、デルタ、OHLC、POC、5秒12本と同じ1分の数量を照合する。時間境界、同内容別約定、遅着、履歴置換、再接続・世代変更、限月分離を検査する。

隔離実ブラウザで両銘柄・全足種・切替・操作・欠け・後着履歴の数値と画素・既存2画面・非表示停止を確認。ダミーは画面とログに明示。固定入力でCPU・RSS・本文量・描画時間を比較し、条件と未確認事項を `docs/FOOTPRINT_IMPLEMENTATION_REPORT.md` に記録する。

公開・本番書込・既存受信停止／再起動・開発上流接続を行わず、検証用ブラウザ・サーバー・接続のみを終了し残存確認する。
