- `inventory.ts`：`freezeInput()` / `verifyInput()` / `assertInputVersions()`。
  原本前後SHA、入力版、別版の不正結合検出。索引棚卸しは日付・件数・coverageのみ読む。
- `model.ts` / `cli.ts` / `splits.ts` / `zip.ts`：
  v2.2分岐、グリッド複数区間、時間制限、validation→test侵入検出、ZIP上限。
- `server/research-v2/grid-v22.json`：今回の全セッションと共通fold境界を固定。
- `prepare-grid.mjs` / `check-grid-budget.mjs`：棚卸しと事前予算判定。
- `compare-batch-pilot.mjs` / `verify-batch.mjs`：市場値照合・復元・全期間検証。
- `server/test/research-v2-batch.test.ts`：新規8試験。
- `server/research-v2/README.md`：再現手順・制約・旧読取側との非互換を記載。

## 時系列分割

共通CTセッション開始日23個を時系列順に並べ、
先頭floor(23×0.6)=13、残りを5/5とした。分割日は全期間の値を見る前に固定。
NQ/GCで同じepoch境界を使用し、NQだけの欠けに合わせて境界を移していない。

|fold|CT期間（半開、すべて17:00）|NQ session / 標本|GC session / 標本|侵入除外|
|---|---|---|---|---:|
|train|09/29〜10/18|13 / 18,720|13 / 18,720|0|
|validation|10/18〜10/25|5 / 7,200|5 / 7,200|0|
|test|10/25〜10/30|4 / 5,760|5 / 7,200|0|

境界はいずれも週末休場を挟み、直前の標本と次foldの最初のas_ofの間は最大Y900秒以上。
したがって今回の実データで除外0は正常。境界を跨ぐ合成例ではtrain→評価、
validation→testの両方を検出し、半開区間のちょうど終了一致は許可した。
ランダム分割なし。testは4/5セッションだけであり、十分な一般化評価を保証しない。
同fold内の重なる窓や、testの過去特徴が以前の期間を使うこと自体は排除しない。
