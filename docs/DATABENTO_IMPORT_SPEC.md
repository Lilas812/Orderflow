# Databento購入約定の隔離取り込み

2026-10-30 ユーザー許可による追記。通常のTICK STREAM収集、保存形式、設定、稼働受信には変更しない。

- 入力は購入原本ZIPのCSV.zst、metadata、manifest、condition。ZIPは変更しない。SHA-256と供給側manifestの全対象ファイルhashを照合する。公式trades形式と実CSVヘッダーを一致させる。
- `pretty_px=true`の小数価格を整数比でティック化する。NQ=0.25、GC=0.10。DBNの固定小数整数として解釈しない。
- `ts_event`を約定時刻、`ts_recv`を受信時刻とし、UTCナノ秒文字列を整数演算でマイクロ秒へ切り捨てる。元のナノ秒、取引所sequence、instrument_id、raw symbol、入力hashと行番号を残す。異なる行を内容一致で除重しない。
- 生CSVに明示された限月を用い、1桁年は記録日の年−1〜年＋4の範囲で一意になる場合だけ正規化する。曖昧なら隔離し、現在限月を遡及しない。限月別の保存先に分離する。
- B=買い主導、A=売り主導。Nはunknownとして原本・分離ステージにも保全し、製品約定へ方向不明のまま採用する。出来高・VP・VWAP・長期VP・フットプリント合計とPOCはB/A/N全量。デルタ・CVD・買売バブル色はB/Aのみ。Nを推測配分しない。限月不明数量とは別項目にする。Nの存在だけを理由に出来高coverageを欠け扱いしない。
- NQ.FUT／GC.FUT親指定に含まれるカレンダースプレッドは標準NQ／GCの価格として扱わない。原本および行番号付きの除外記録を保持する。解析エラーも別保存し、その供給日の適用を保留する。
- 入力をストリーム展開する。日／月全体の展開結果をRAMへ載せない。変換済みステージは入力hash別、適用結果は不変generation別、原本とは別の隔離先とする。
- 同じアーカイブhash＋UTC半開区間＋採用方針版の実行は、保存済み出力hashを再照合して終了する。B/Aのみの旧世代をall-outright-v2の結果とみなさない。新世代を生成し旧世代は残す。分離ステージは元CSV ordinal順にストリーム合流し、時刻の巻き戻りを並べ替えない。途中まで検証した入力ステージは再利用するが、検証前の.partialは採用しない。
- 既存データはコピーと各ファイルhashを保全。限月が不明な重複時間、供給condition不明／degraded、解析失敗のある日を既存行へ上書きしない。
- 確認済みの限月・UTC範囲だけを時間ファイル内で置換する。対象外行の内容と相対順序を維持する。新gzipを一時ファイルへ書き、全行の順序付きhashを製品読取で再照合後に置換する。
- coverageとimport履歴は保存後の照合に成功してから更新し、最終active pointerは全generationの照合・再集計後に原子的に切り替える。中断前のactiveを維持し、原本・baselineを削除しない。
- 対象の全歴史セッションについて既存VolumeProfile／LongAggregateから日次・長期を再構築する。直近7日で打ち切らない。限月不明、未取得、境界の不足は途中集計／gapsのままにする。Nを含めた購入CSV内全量との一致と、供給期間／取引所の完全性は区別する。

2026-10-30方向不明数量の追記：VP levelsは任意4要素目、日次pointsは任意6要素目、LONG VPのvp30mは任意6要素目、bars1mは任意9要素目に方向不明枚数を持つ。既知buy/sellのみの従来長の配列も受理し、不明枚数は0。旧フロントは拡張配列を受理できないため、公開には対応フロント／サーバーをそろえる（今回は未公開）。保存JSONLのsideはunknownを追加受理し、既存buy/sell行は変更しない。
- 板は生成・補完しない。本番書込、上流接続、Publish、受信再起動は取り込みコマンドから実行しない。

データのavailable・hash・全行照合は供給範囲と変換の証拠であり、取引所／供給フィードの完全性保証ではない。
