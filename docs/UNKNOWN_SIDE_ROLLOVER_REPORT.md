# GCのN約定：日付・時間帯・ロール時期の追加調査

## 結論
- セッション全体が購入対象期間内に入る21日では、N数量最多は10/22の3,877枚。N/B/A数量比の最高は10/16の2.5440%。
- 時刻別合計の最多はCT08–09時＝JST22–23時の4,734枚。日付を含む1時間枠ではCT10/16 11–12時＝JST10/17 01–02時の936枚。
- CME公式のGCZ6 First Notice Day（FND）は2026/11/30。11月後半の主な移行時期はデータ外。GCG7がGCZ6を日次出来高で上回った日は0/21日であり、Z6→G7の主力交代を観測していない。
- 期間内で「FNDに近づくほどN数量が増える」傾向は確認できない。残日数とN数量の相関はほぼ0。GCZ6自身のN/B/A比は、むしろFNDから遠い日に高い方向の相関だった。ただし1か月・単一ロールの前段だけの記述統計。
- 通常出来高の多さを補正しても10/16などに局所的なN増加がある。一方、スプレッド照合が強い群とその他の時間分布には差がある。これをロール目的の注文や個人のポジション移動と断定することはできない。

## 4. GCZ6→GCG7のロールとの関係
- CME公式契約カレンダー：GCZ26のFirst Positionは11/27、First Noticeは11/30、最終取引は12/29。GCG27のFirst Noticeは2027/1/29。FNDと最終取引日、ベンダーの連続足切替日を混同しない。
- 全購入区間のGCZ6出来高2,908,774枚、GCG7出来高31,008枚。両限月の合計に占めるGCG7は1.0548%。完全21日の日別GCG7比率は0.6914〜1.7889%。GCZ6より多い日は一度もない。
- 10/22のN最多日におけるGCG7比率は1.7723%。月末の10/29は1.1192%であり、月末へ単調に主力が移った形ではない。10/22はFNDの39暦日前。
- GCZ6-GCG7スプレッド自体は取引されている。日次枚数は10/22が19,262枚、10/23が20,009枚、10/29が14,871枚。ただしスプレッド約定には新規・手仕舞い・裁定などもあり、「全てがロール注文」とは同定できない。Nは脚の約定として別に評価し、スプレッド出来高をNに加算していない。
- 別限月GCV6のFND=9/30、GCX6のFND=10/30は期間の端に近い。全GCを合算したNを全てZ6→G7ロールと解釈してはいけない。GCZ6に絞った比率もCSVと下表に収録。
- 主力移行の操作的な確認は日次出来高の逆転。建玉・口座・参加者のポジション移動はデータにない。実際の11月後半を含まないため「ロール期にNが増える/増えない」という一般則は検証不能。
## 5. FNDまでの残り営業日との関係
- FND日付そのものはCME公式カレンダーで確認済み。残日数は当日を除きFND当日を含む。
- 主列は再現可能な銀行営業日proxy：土日と10/12・11/11・11/26の米国銀行休日を除く。公式のCOMEX受渡営業日カレンダーを完全取得した値ではないため、公式残営業日と断定しない。11/11の銀行休業と通常のEOD処理はCME告知でも区別されている。
- 感度確認として土日だけを除く残平日数も併記。21日の範囲は銀行proxy20〜39日、土日除外22〜42日。11月のFND直前に相当する数日間のデータはない。

## 6. 通常出来高を考慮してもNが多いか
- 完全21日の総N/B/Aは1.7404%。日別B/A数量とN数量のPearson相関は0.7836で、全体の取引活発化がN数量の増加をかなり伴う。
- それでも10/16は2.5440%（全体比率の1.46倍）、10/28は1.2636%。最多数量日10/22の2.0950%よりも、10/16の比率が高い。
- 追加の記述的補正：対象日を除いた20日の「同じ限月×CT時間」のN/B/A比率に、対象日の同区分のB/A数量を掛けて期待N数量を足し上げる（leave-one-day-out）。推定不能な区分のB/AはCSVに残す。因果モデル・予測検証ではない。

| 2026-10-16 | 3,268 | 2,487.39 | 1.314倍 | 3 |
| 2026-10-02 | 3,340 | 2,780.07 | 1.201倍 | 3 |
| 2026-10-15 | 2,809 | 2,432.57 | 1.155倍 | 2 |

- 時刻合算ではCT11–12時のN/B/Aが2.5683%、CT15–16時が2.3967%。最多数量のCT08–09時は1.7741%。
- 個別時間ではCT10/16 15–16時：N438枚 / B/A2,048枚=21.3867%、CT10/15 02–03時：570 / 4,690=12.1535%、CT10/21 21–22時：706 / 7,518=9.3908%、CT10/16 11–12時：936 / 10,992=8.5153%。小分母の高比率だけでなく936枚の量的増加も存在する。
- 通常出来高だけでは一様なN発生率にならない。ただし多数の時間枠から事後選択した上位値であり、独立な約定を仮定した小さいp値や再現可能な異常シグナルとは主張しない。
