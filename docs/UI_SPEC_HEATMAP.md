# UI_SPEC_HEATMAP.md — ヒートマップ画面 UI仕様

最終更新：2026-10-27
表記：【確定】決定済み／【推定】参照画像から読んだだけで要確認／【案】提案で未採用／【未決定】ユーザーが決める
寸法は参照画像（約560×440px）からの目測。実装では比率として扱う。

---

## 1. 画面の考え方

「置かれている注文（板）」と「成立した取引（約定）」を横に並べ、1画面で見比べられるようにする。

| 領域 | 表すもの |
| --- | --- |
| ヒートマップ | 板の過去（時間ごとの厚みの推移） |
| 現在の板 | 今この瞬間の板の厚み |
| 大口板列 | 今の板のうち、閾値を超えた大口だけ |
| VP | 約定した量の累計 |
| デルタヒストグラム | 時間ごとの買い約定−売り約定 |

## 2. レイアウト【推定】

```
┌─┬──────────────────────────┬─────────┬───┬────────┬────────────┐
│ │ ヒートマップ本体          ┆ 現在の板 │価 │ 大口板列 │ VP          │
│ツ│ （価格ライン・約定バブル） ┆         │格 │        │            │
│ー│                          ┆         │軸 │        │            │
│ル│                          ┆         │   │        │            │
│バ├──────────────────────────┼─────────┼───┼────────┴────────────┤
│ー│ デルタヒストグラム         │ 空き     │目 │ 空き                │
│ ├──────────────────────────┤         │盛 │                     │
│ │ 時間軸                    │         │り │                     │
└─┴──────────────────────────┴─────────┴───┴─────────────────────┘
（┆ は同じ枠の中の区切り。「価格軸」の列は上が価格の目盛り、下がデルタの目盛り）
```

| 領域 | 幅 | 高さ | 位置 |
| --- | --- | --- | --- |
| ツールバー | 固定幅（44px前後）【案】 | 全高 | 左端 |
| ヒートマップ本体 | 52% | 79% | 左枠の左側 |
| 現在の板 | 12% | 79% | 左枠の右端（ヒートマップと同じ枠） |
| 価格軸 | 5% | 79% | 左枠と大口板列の間（左枠の外） |
| 大口板列 | 10% | 79% | 中央 |
| VP | 19% | 79% | 右端 |
| デルタヒストグラム | 52% | 19% | ヒートマップ本体の下 |
| 時間軸 | 52% | 2% | 最下部 |
| デルタの目盛り | 5% | 19% | 価格軸の列の下（デルタヒストグラムと同じ高さ） |

- 縦の価格軸は、ヒートマップ・現在の板・大口板列・VP で共通。どの列でも同じ高さが同じ価格。【確定】
- デルタヒストグラムは、ヒートマップ本体と時間軸を共有する。【推定】
- 価格軸は左枠の中ではなく、左枠と大口板列の間の独立した列にする。同じ列の下段は、デルタヒストグラムの目盛り（＋ / 0 / −）にする。参照画像でも、数字の列は左枠の境界線のすぐ右にあり、その下にデルタの目盛りがある。【確定】（2026-10-27 ユーザー決定。幅5%）
- 大口板列の15%は、参照画像で数字の列を含めて測っていたので、価格軸を分けたぶん10%にする。ヒートマップ本体の幅は変えない。【確定】
- ツールバーは参照画像では幅2%ほどだが、指で押せる大きさを確保するため、比率ではなく固定幅にする。ほかの領域の比率は、ツールバーを除いた幅に対して当てはめる。【案】

## 3. 各領域

### 3.1 ツールバー（左端）

- 左端に縦に並ぶアイコンで、機能を呼び出す。【確定】
- 置くアイコンは次の2つ。上から順に並べる。【確定】

| アイコン | 押したときの動き | 状態 |
| --- | --- | --- |
| 設定 | 画面中央に設定画面が開く（3.9） | 【確定】 |
| 表示リセット | その場で現在値に戻り、拡大率を初期値に戻す。画面は開かない | 【確定】 |

- 表示のオン・オフ（各列・バブルなど）と描画ツールは、ツールバーには置かない。【確定】
- 各列の表示のオン・オフが必要になったら、設定画面の中に入れる。【案】
- アイコンは線画。PC ではマウスを乗せると名前が出る。【案】
- アイコンは指で押せる大きさ（44px四方前後）にする。【案】
- 参照画像はアイコンが4つほどあるが、このアプリでは2つにする。

### 3.2 ヒートマップ

- 背景は黒。横軸＝時間、縦軸＝価格で、各価格の板の厚みを色で塗る。【確定】
- 色の段階は 薄い青 → 紫 → 白。特に大きい板はオレンジ〜赤の横線。【推定】
- 左端に青い短い横線がいくつかある。用途不明。【推定】
- 色の濃さのスケール：画面に見えている範囲の上位1%の枚数を最大色にして頭打ち。何％かは設定で変えられる。【確定】（詳細は SPEC 7 節）
- 板が来なかった2秒以下の隙間は、直前の列で埋めて描く。3秒以上は背景色のまま。【確定】
- 板の価格はティック幅で丸めてノイズを減らす（参考記事の方式）。【案】

### 3.3 価格ライン・約定バブル

- 現在値の推移を薄紫の線で描く。現在値には白い点線の水平線。【推定】
- 約定バブル：緑＝買い、紫＝売り、大きさ＝量。【推定】
- バブルの出し方は2択。【未決定】
  - 1約定ごと（サイズが閾値以上のものだけ）
  - 参考記事の方式：1分足×2ティックごとにデルタを集計し、偏りが大きい箇所に出す

### 3.4 現在の板（ヒートマップ枠の右端）

- 今この瞬間の板の厚みを、右端から左へ伸びる横棒で表示。紫1色。【推定】
- 最良気配のあたりにグレーの帯。【推定】
- 棒の長さのスケールは、ヒートマップの色と同じ方式にそろえる。【案】

### 3.5 大口板列（中央の列）

- 今の板のうち、閾値を超えた価格だけを横棒で表示する。【確定】
- マゼンタ1色で、買い板・売り板の色分けはしない。【確定】
- 買いか売りかは現在値より下か上かで判別できるので、色は別の情報に使う。【案】
  - 濃さ＝枚数の大きさ
  - 色の変化＝置かれている時間
- 閾値は「枚数固定」と「相対値（表示範囲平均の◯倍、上位◯%）」を切り替えられるようにする。【案】
- 継続時間の条件：◯秒以上置かれた板だけを表示し、一瞬で消える板を除外する。【案】
- 表示範囲：現在値から上下◯ティック以内。【案】
- L2 は価格ごとの合計枚数しか来ないため、1つの大口注文か小口の集まりかは区別できない。【確定】
- 参照画像で列の左端にある数字は、独立した価格軸の列として扱う（3.10）。上部に隠された表示がある。【推定】

### 3.6 VP（右端）

- 約定量の累計を、価格ごとの横棒で表示する。【確定】
- バリューエリア（出来高の70%帯）をオレンジで強調。【推定】
- 点線の水平線が1本。POC か VAH と思われる。【推定】
- 集計期間：当日セッション／表示範囲／固定期間。【未決定】

### 3.7 デルタヒストグラム（下段）

- 見出しは「Delta」。区間ごとの買い約定−売り約定。＋は白で上向き、−は紫で下向き。【推定】
- 集計単位（1本あたり何秒か）。【未決定】

### 3.8 時間軸

- 最下部に時刻ラベル（hh:mm:ss）。【推定】
- 表示する時刻のタイムゾーン：日本時間と米国中部時間（America/Chicago、夏時間に追従）を切り替えられる。初期値は日本時間。切り替えは設定画面で行う（Phase 9）。【確定】

### 3.9 設定画面

- ツールバーの設定アイコンを押すと、画面中央に開く。チャートの上に重なる。【確定】
- 開いている間、後ろのチャートは暗くするが、更新は止めない。【案】
- 閉じ方：右上の×、画面外の暗い部分を押す、PC は Esc キー。【案】
- 変更は「保存」を押したときに反映し、サーバーに保存して端末間で共有する。閉じるだけなら変更は捨てる。【案】
- 入れる項目（それぞれの値の決め方は未決定事項として残す）：【案】
  - ヒートマップ：列の幅、色のスケール方式、価格の丸め幅
  - 約定バブル：出し方、閾値
  - 現在の板：棒の長さのスケール
  - 大口板列：閾値の方式と値、継続時間、表示範囲、色に載せる情報
  - VP：集計期間
  - デルタヒストグラム：集計単位
  - 時間軸：タイムゾーン

### 3.10 価格軸（左枠と大口板列の間）

- 価格の目盛りを縦に並べる。価格はティック整数×0.25 で表示する。拡大率に合わせて目盛りの間隔を変える。【確定】
- 現在値の位置に、目立つ色で現在値のラベルを出す（Phase 4）。【案】
- 上下ドラッグで価格方向のズームをする操作は、この列で受ける（5 節）。【確定】
- 下段（デルタヒストグラムと同じ高さ）は、デルタの目盛り（＋ / 0 / −）を出す（Phase 8）。【確定】

## 5. 操作

- チャートの移動と拡大縮小は、指・マウスでチャートを直接触って行う。アイコンでは行わない。【確定】
- 機能の呼び出し（設定・表示リセット）は、左端のツールバーのアイコンで行う。【確定】
- 具体的な割り当て：【案】
  - マウスホイール：時間方向のズーム
  - ドラッグ：時間方向のスクロール
  - 価格軸の上下ドラッグ：価格方向のズーム
  - タッチ：ピンチでズーム、1本指でスクロール
  - ダブルクリック／ダブルタップ：現在値に戻る（ツールバーの表示リセットと同じ動き）

## 6. スマホ【未決定】

- iPhone の縦画面幅では4列が収まらない。
- 案：ヒートマップ＋現在の板を主表示にし、大口板列と VP はタブで切り替える。
- ツールバーの位置（左に縦並びのままか、下に横並びか）は、スマホ対応のフェーズで決める。
