# UI_SPEC_HEATMAP.md — ヒートマップ画面 UI仕様

最終更新：2026-10-27（現在の板をヒートマップに重ねる形に変更）
表記：【確定】決定済み／【推定】参照画像から読んだだけで要確認／【案】提案で未採用／【未決定】ユーザーが決める
寸法は参照画像（約560×440px）からの目測。実装では比率として扱う。

---

## 1. 画面の考え方

「置かれている注文（板）」と「成立した取引（約定）」を横に並べ、1画面で見比べられるようにする。

| 領域 | 表すもの |
| --- | --- |
| ヒートマップ | 板の過去（時間ごとの厚みの推移） |
| 現在の板 | 今この瞬間の板の厚み |
| 大口板列 | 今の板のうち、閾値を超えた大口だけ |
| VP | 約定した量の累計 |
| デルタヒストグラム | 時間ごとの買い約定−売り約定 |

## 2. レイアウト【推定】

```
┌─┬────────────────────────────────────┬───┬────────┬────────────┐
│ │ ヒートマップ本体                      │価 │ 大口板列 │ VP          │
│ツ│ （価格ライン・約定バブル）  ┆ 現在の板 │格 │        │            │
│ー│                          ┆（右端20%│軸 │        │            │
│ル│                          ┆ に重ねる）│   │        │            │
│バ├────────────────────────────────────┼───┼────────┴────────────┤
│ー│ デルタヒストグラム                   │目 │ 空き                │
│ ├────────────────────────────────────┤盛 │                     │
│ │ 時間軸                              │り │                     │
└─┴────────────────────────────────────┴───┴─────────────────────┘
（┆ は枠ではなく、ライブで追いかけているときの最新の列の位置。その右の20%に今の板の棒を半透明で重ねる。
  「価格軸」の列は上が価格の目盛り、下がデルタの目盛り）
```

| 領域 | 幅 | 高さ | 位置 |
| --- | --- | --- | --- |
| ツールバー | 固定幅（44px前後）【案】 | 全高 | 左端 |
| ヒートマップ本体 | 66% | 79% | 左の枠。右端20%に現在の板を重ねる |
| 価格軸 | 5% | 79% | ヒートマップ本体と大口板列の間 |
| 大口板列 | 10% | 79% | 中央 |
| VP | 19% | 79% | 右端 |
| デルタヒストグラム | 66% | 19% | ヒートマップ本体の下 |
| 時間軸 | 66% | 2% | 最下部 |
| デルタの目盛り | 5% | 19% | 価格軸の列の下（デルタヒストグラムと同じ高さ） |

- 現在の板は独立した枠にせず、ヒートマップ本体の右端に重ねて描く。過去の板（ヒートマップ）が右へ流れてきて、そのまま今の板の棒につながって見えるようにするため。参照画像もそうなっている。【確定】（2026-10-27 ユーザー決定。それまでの「現在の板 12%」の枠はなくし、ヒートマップを54%から66%にする）
- 縦の価格軸は、ヒートマップ・現在の板・大口板列・VP で共通。どの列でも同じ高さが同じ価格。【確定】
- デルタヒストグラムは、ヒートマップ本体と時間軸を共有する。【推定】
- 価格軸はヒートマップの枠の中ではなく、ヒートマップと大口板列の間の独立した列にする。同じ列の下段は、デルタヒストグラムの目盛り（＋ / 0 / −）にする。参照画像でも、数字の列はヒートマップの枠の境界線のすぐ右にあり、その下にデルタの目盛りがある。【確定】（2026-10-27 ユーザー決定。幅5%）
- 大口板列の15%は、参照画像で数字の列を含めて測っていたので、価格軸を分けたぶん10%にする。【確定】
- 幅の合計を100%にするため、余った2%はヒートマップ本体に足した（デルタヒストグラムと時間軸も同じ幅）。【確定】（2026-10-27 ユーザー決定）
- ツールバーは参照画像では幅2%ほどだが、指で押せる大きさを確保するため、比率ではなく固定幅にする。ほかの領域の比率は、ツールバーを除いた幅に対して当てはめる。【案】

## 3. 各領域

### 3.1 ツールバー（左端）

- 左端に縦に並ぶアイコンで、機能を呼び出す。【確定】
- 置くアイコンは次の2つ。上から順に並べる。【確定】

| アイコン | 押したときの動き | 状態 |
| --- | --- | --- |
| 設定 | 画面中央に設定画面が開く（3.9） | 【確定】 |
| 表示リセット | その場で現在値に戻り、拡大率を初期値に戻す。画面は開かない | 【確定】 |

- 表示のオン・オフ（各列・バブルなど）と描画ツールは、ツールバーには置かない。【確定】
- 各列の表示のオン・オフが必要になったら、設定画面の中に入れる。【案】
- アイコンは線画。PC ではマウスを乗せると名前が出る。【案】
- アイコンは指で押せる大きさ（44px四方前後）にする。【案】
- 参照画像はアイコンが4つほどあるが、このアプリでは2つにする。

### 3.2 ヒートマップ

- 背景は黒。横軸＝時間、縦軸＝価格で、各価格の板の厚みを色で塗る。【確定】
- 色の段階は 薄い青 → 紫 → 白。特に大きい板はオレンジ〜赤の横線。【推定】
- 左端に青い短い横線がいくつかある。用途不明。【推定】
- 色の濃さのスケール：画面に見えている範囲の、注文のある価格のマスの上位1%の枚数を最大色にして頭打ち。何％かは設定で変えられる。【確定】（詳細は SPEC 7 節）
- 板が来なかった2秒以下の隙間は、直前の列で埋めて描く。3秒以上は背景色のまま。【確定】
- 板の価格はティック幅で丸めてノイズを減らす（参考記事の方式）。【案】

### 3.3 価格ライン・約定バブル

- 価格ライン：各秒の最後の約定価格を薄紫の線（太さ1.5px）で結ぶ。約定のない秒は直前の価格のまま。【確定】
- 現在値：最新の約定の価格に、白い点線の水平線。価格軸の列にラベル。【確定】
- 約定バブル：1秒×1ティックごとの合計枚数が10枚以上（設定で変更可）の場所に出す。色は買いが多ければ緑、売りが多ければ紫、同じなら灰。面積が枚数に比例し、半径3〜14px。塗りは不透明度0.8、縁に1pxの線（塗りを約40%暗くした色）。【確定】（2026-10-27 ユーザー決定）
- 参考記事の方式（1分×2ティックのデルタ集計）は採らない。NQ は1枚の約定が大半なので、1約定ごとでは細かい点だらけになり、1分単位では粗すぎるため。
- 詳細は SPEC 7.1 節。

### 3.4 現在の板（ヒートマップ本体の右端に重ねる）

- 今この瞬間の板の枚数を、価格ごとの横棒（横向きのヒストグラム）で表示する。ヒートマップ本体の右端から左へ伸ばし、半透明で重ねる。【確定】（2026-10-27 ユーザー決定）
- 色：売り板は紫 `#8a3cff`、買い板は薄いグレー `#d9d9d9`。現在値の上下でひと目で分かるようにする。【確定】
- 棒の長さの上限は、ヒートマップ本体の幅の20%。長さは、ヒートマップの色の基準（上位1%の値）に対する割合。【確定】
- ライブで追いかけているときは、最新の列をヒートマップ本体の右端から20%手前に置き、右側の20%を今の板の棒の場所にする。過去へスクロールしたときは、その部分にもヒートマップが描かれ、棒が半透明で重なる。【確定】
- 以前の「最良気配のグレーの帯」はやめる（参照画像のグレーは買い板の棒だった）。
- 詳細は SPEC 7.2 節。

### 3.5 大口板列（中央の列）

- 今の板のうち、閾値を超えた価格だけを横棒で表示する。【確定】
- マゼンタ1色で、買い板・売り板の色分けはしない。【確定】
- 買いか売りかは現在値より下か上かで判別できるので、色の濃さは「置かれている時間」に使う。新しい板は薄く（不透明度0.35）、5分以上残っている板は濃く（1.0）。【確定】
- 棒の長さは枚数。表示中の大口板の最大の枚数を、列の幅いっぱいにする。【確定】
- 閾値：その時点の板（両側）の枚数の上位2%。設定で変えられる。【確定】
- 継続時間の条件：5秒以上置かれた板だけを表示し、一瞬で消える板を除外する。設定で変えられる。【確定】
- 表示範囲：受け取っている400段のうち、画面の価格帯に入るものすべて。【確定】
- 判定は1秒の列で行うので、表示は1〜3秒遅れる。【確定】
- 詳細は SPEC 7.3 節。（2026-10-27 ユーザー決定）
- L2 は価格ごとの合計枚数しか来ないため、1つの大口注文か小口の集まりかは区別できない。【確定】
- 参照画像で列の左端にある数字は、独立した価格軸の列として扱う（3.10）。上部に隠された表示がある。【推定】

### 3.6 VP（右端）

- 約定量の累計を、価格ごとの横棒で表示する。【確定】
- バリューエリア（出来高の70%帯）をオレンジで強調。【推定】
- 点線の水平線が1本。POC か VAH と思われる。【推定】
- 集計期間：当日セッション／表示範囲／固定期間。【未決定】

### 3.7 デルタヒストグラム（下段）

- 見出しは「Delta」。区間ごとの買い約定−売り約定。＋は白で上向き、−は紫で下向き。【推定】
- 集計単位（1本あたり何秒か）。【未決定】

### 3.8 時間軸

- 最下部に時刻ラベル（hh:mm:ss）。【推定】
- 表示する時刻のタイムゾーン：日本時間と米国中部時間（America/Chicago、夏時間に追従）を切り替えられる。初期値は日本時間。切り替えは設定画面で行う（Phase 9）。【確定】

### 3.9 設定画面

- ツールバーの設定アイコンを押すと、画面中央に開く。チャートの上に重なる。【確定】
- 開いている間、後ろのチャートは暗くするが、更新は止めない。【案】
- 閉じ方：右上の×、画面外の暗い部分を押す、PC は Esc キー。【案】
- 変更は「保存」を押したときに反映し、サーバーに保存して端末間で共有する。閉じるだけなら変更は捨てる。【案】
- 入れる項目（それぞれの値の決め方は未決定事項として残す）：【案】
  - ヒートマップ：列の幅、色のスケール方式、価格の丸め幅
  - 約定バブル：出し方、閾値
  - 現在の板：棒の長さのスケール
  - 大口板列：閾値の方式と値、継続時間、表示範囲、色に載せる情報
  - VP：集計期間
  - デルタヒストグラム：集計単位
  - 時間軸：タイムゾーン

### 3.10 価格軸（ヒートマップと大口板列の間）

- 価格の目盛りを縦に並べる。価格はティック整数×0.25 で表示する。拡大率に合わせて目盛りの間隔を変える。【確定】
- 上下ドラッグで価格方向のズームをする操作は、この列で受ける（5 節）。【確定】
- 下段（デルタヒストグラムと同じ高さ）は、デルタの目盛り（＋ / 0 / −）を出す（Phase 8）。【確定】
- 現在値のラベル：白地に黒字で、価格を出す（Phase 4）。【確定】

## 5. 操作

- チャートの移動と拡大縮小は、指・マウスでチャートを直接触って行う。アイコンでは行わない。【確定】
- 機能の呼び出し（設定・表示リセット）は、左端のツールバーのアイコンで行う。【確定】
- 具体的な割り当て：【案】
  - マウスホイール：時間方向のズーム
  - ドラッグ：時間方向のスクロール
  - 価格軸の上下ドラッグ：価格方向のズーム
  - タッチ：ピンチでズーム、1本指でスクロール
  - ダブルクリック／ダブルタップ：現在値に戻る（ツールバーの表示リセットと同じ動き）

## 6. スマホ【未決定】

- iPhone の縦画面幅では4列が収まらない。
- 案：ヒートマップ＋現在の板を主表示にし、大口板列と VP はタブで切り替える。
- ツールバーの位置（左に縦並びのままか、下に横並びか）は、スマホ対応のフェーズで決める。
