## 1. 画面の考え方

「置かれている注文（板）」と「成立した取引（約定）」を横に並べ、1画面で見比べられるようにする。

| 領域 | 表すもの |
| --- | --- |
| ヒートマップ | 板の過去（時間ごとの厚みの推移） |
| 現在の板 | 今この瞬間の板の厚み |
| 大口板列 | 今の板のうち、閾値を超えた大口だけ |
| VP | 約定した量の累計 |
| デルタヒストグラム | 時間ごとの買い約定−売り約定 |

```
│ │ ヒートマップ本体                      │価 │ 大口板列 │ VP          │
│ツ│ （価格ライン・約定バブル）  ┆ 現在の板 │格 │        │            │
│ー│                          ┆（右端20%│軸 │        │            │
│ル│                          ┆ に重ねる）│   │        │            │
│バ├────────────────────────────────────┼───┼────────┴────────────┤
│ー│ デルタヒストグラム                   │目 │ 空き                │
│ ├────────────────────────────────────┤盛 │                     │

（┆ は枠ではなく、ライブで追いかけているときの最新の列の位置。その右の20%に今の板の棒を半透明で重ねる。
  「価格軸」の列は上が価格の目盛り、下がデルタの目盛り）
```

| 領域 | 幅 | 高さ | 位置 |
| --- | --- | --- | --- |
| ツールバー | 固定幅 44 CSS px【確定】 | 全高 | 左端 |
| ヒートマップ本体 | 66% | 79% | 左の枠。右端20%に現在の板を重ねる |
| 価格軸 | 5% | 79% | ヒートマップ本体と大口板列の間 |
| 大口板列 | 10% | 79% | 中央 |
| VP | 19% | 79% | 右端 |
| デルタヒストグラム | 66% | 19% | ヒートマップ本体の下 |
| 時間軸 | 66% | 2% | 最下部 |
| デルタの目盛り | 5% | 19% | 価格軸の列の下（デルタヒストグラムと同じ高さ） |

- 現在の板は独立した枠にせず、ヒートマップ本体の右端に重ねて描く。過去の板（ヒートマップ）が右へ流れてきて、そのまま今の板の棒につながって見えるようにするため。参照画像もそうなっている。【確定】（2026-10-27 ユーザー決定。それまでの「現在の板 12%」の枠はなくし、ヒートマップを54%から66%にする）
- 縦の価格軸は、ヒートマップ・現在の板・大口板列・VP で共通。どの列でも同じ高さが同じ価格。【確定】
- デルタヒストグラムは、ヒートマップ本体と時間軸を共有する。【推定】
- 価格軸はヒートマップの枠の中ではなく、ヒートマップと大口板列の間の独立した列にする。同じ列の下段は、デルタヒストグラムの目盛り（＋ / 0 / −）にする。参照画像でも、数字の列はヒートマップの枠の境界線のすぐ右にあり、その下にデルタの目盛りがある。【確定】（2026-10-27 ユーザー決定。幅5%）
- 大口板列の15%は、参照画像で数字の列を含めて測っていたので、価格軸を分けたぶん10%にする。【確定】
- 幅の合計を100%にするため、余った2%はヒートマップ本体に足した（デルタヒストグラムと時間軸も同じ幅）。【確定】（2026-10-27 ユーザー決定）
- ツールバーは参照画像では幅2%ほどだが、指で押せる大きさを確保するため、比率ではなく固定幅（44 CSS px）にする。ほかの領域の比率は、ツールバーを除いた幅に対して当てはめる。【確定】（2026-10-28）

## 3. 各領域

### 3.1 ツールバー（左端）

- 左端に縦に並ぶアイコンで、機能を呼び出す。【確定】
- 置くアイコンは次の2つ。上から順に並べる。【確定】

| アイコン | 押したときの動き | 状態 |
| --- | --- | --- |
| 設定 | 画面中央に設定画面が開く（3.9） | 【確定】 |
| 表示リセット | その場で現在値に戻り、拡大率を初期値に戻す。画面は開かない | 【確定】 |

- 表示のオン・オフ（各列・バブルなど）と描画ツールは、ツールバーには置かない。【確定】
- 各列の表示のオン・オフは、今は作らない。必要になったら設定画面の中に入れる。【確定】（2026-10-28）
- アイコンは線画（SVG をコードに直接書く。アイコンのライブラリは足さない）。PC ではマウスを乗せると名前が出る。【確定】（2026-10-28）
- 押せる範囲は 44 × 44 CSS px。ツールバーの背景は `#000000`、右端に 1px の線 `#333333`。アイコンの線は `#d9d9d9`、押している間は `#ffffff`。【確定】（2026-10-28）
- 参照画像はアイコンが4つほどあるが、このアプリでは2つにする。

### 3.2 ヒートマップ

- 背景は黒。横軸＝時間、縦軸＝価格で、各価格の板の厚みを色で塗る。【確定】
- 色の段階は 薄い青 → 紫 → 白。特に大きい板はオレンジ〜赤の横線。【推定】
- 左端に青い短い横線がいくつかある。用途不明。【推定】
- 色の濃さのスケール：上限（これ以上は最大色）・下限（これ以下は塗らない）・コントラストの3つで決める。上限は「自動（見えている範囲の上位％、初期値1%）」か「枚数で指定」、下限は「なし（初期値）」「下位％」「枚数で指定」。Bookmap の upper / lower cutoff と同じ考え方。【確定】（2026-10-28 ユーザー決定。詳細は SPEC 7 節）
- 左上に、今の上限と下限の値と決め方を小さく出す（例「上限 19（上位1%）／下限 なし」）。【確定】
- 板が来なかった2秒以下の隙間は、直前の列で埋めて描く。3秒以上は背景色のまま。【確定】
- 板の価格はティック幅で丸めてノイズを減らす（参考記事の方式）。【案】

### 3.3 価格ライン・約定バブル

- 価格ライン：各秒の最後の約定価格を薄紫の線（太さ1.5px）で結ぶ。約定のない秒は直前の価格のまま。【確定】
- 現在値：最新の約定の価格に、白い点線の水平線。価格軸の列にラベル。【確定】
- 約定バブル：1秒×1ティックごとの合計枚数が10枚以上（設定で変更可）の場所に出す。色は買いが多ければ緑、売りが多ければ紫、同じなら灰。面積が枚数に比例し、半径3〜14px。塗りは不透明度0.8、縁に1pxの線（塗りを約40%暗くした色）。【確定】（2026-10-27 ユーザー決定）
- バブルの大きさは設定の倍率（0.5〜3倍、初期値1倍）で変えられる。半径の下限・上限も同じ倍率で変わる。【確定】（2026-10-28 ユーザー決定）
- バブルの作り方を設定で選べる（DeepCharts の Volume Bubbles が参考）：表示の種類（出来高・デルタ・売買分割）、まとめ方（時間：1・5・15・60秒・自動、価格：1〜20ティック・自動）、大きさの伸び方（平方根・直線・対数）、色の付け方（多いほうの色・割合で混ぜる）、不透明度。初期値は今までの見た目のまま。【確定】（2026-10-28 ユーザー決定。詳細は SPEC 7.1）
- 売買分割：1つの円を縦に半分に分け、左が売り（紫）、右が買い（緑）。それぞれの半円の大きさは、その側の枚数。
- 参考記事の方式（1分×2ティックのデルタ集計）は採らない。NQ は1枚の約定が大半なので、1約定ごとでは細かい点だらけになり、1分単位では粗すぎるため。
- 詳細は SPEC 7.1 節。

### 3.4 現在の板（ヒートマップ本体の右端に重ねる）

- 今この瞬間の板の枚数を、価格ごとの横棒（横向きのヒストグラム）で表示する。ヒートマップ本体の右端から左へ伸ばし、半透明（初期値0.5、設定で変更可）で重ねる。【確定】（2026-10-27 ユーザー決定、2026-10-28 に不透明度を変更）
- 最新の列より右の空白は、今の板をヒートマップと同じ色で横に塗る（今の板の色の帯）。過去の板のヒートマップが、そのまま今の板の色につながって見える。棒はその上に半透明で重なる。【確定】（2026-10-28 ユーザー決定）
- 色：売り板は紫 `#8a3cff`、買い板は薄いグレー `#d9d9d9`。現在値の上下でひと目で分かるようにする。【確定】
- 棒の長さの上限は、ヒートマップ本体の幅の10%（右の20%の空白の半分。設定で5〜20%）。長さは、ヒートマップの色の基準（上位1%の値）に対する割合。【確定】（2026-10-28 ユーザー決定。それまでは20%）
- 板のデータは1ティック（0.25）ごと・両側400段で、TICK STREAM から取れるいちばん細かいもの。これより細かくはできない。価格方向に拡大すると、1段ずつの棒が太く見える。
- ライブで追いかけているときは、最新の列をヒートマップ本体の右端から20%手前に置き、右側の20%を今の板の棒の場所にする。過去へスクロールしたときは、その部分にもヒートマップが描かれ、棒が半透明で重なる。【確定】
- 以前の「最良気配のグレーの帯」はやめる（参照画像のグレーは買い板の棒だった）。
- 詳細は SPEC 7.2 節。

### 3.5 大口板列（中央の列）

- 今の板のうち、閾値を超えた価格だけを横棒で表示する。【確定】
- マゼンタ1色で、買い板・売り板の色分けはしない。【確定】
- 買いか売りかは現在値より下か上かで判別できるので、色の濃さは「置かれている時間」に使う。新しい板は薄く（不透明度0.35）、5分以上残っている板は濃く（1.0）。【確定】
- 棒の長さは枚数。表示中の大口板の最大の枚数を、列の幅いっぱいにする。【確定】
- 閾値：その時点の板（両側）の枚数の上位2%。設定で変えられる。【確定】
- 継続時間の条件：5秒以上置かれた板だけを表示し、一瞬で消える板を除外する。設定で変えられる。【確定】
- 表示範囲：受け取っている400段のうち、画面の価格帯に入るものすべて。【確定】
- 判定は1秒の列で行うので、表示は1〜3秒遅れる。【確定】
- 詳細は SPEC 7.3 節。（2026-10-27 ユーザー決定）
- L2 は価格ごとの合計枚数しか来ないため、1つの大口注文か小口の集まりかは区別できない。【確定】
- 参照画像で列の左端にある数字は、独立した価格軸の列として扱う（3.10）。上部に隠された表示がある。【推定】

### 3.6 VP（右端）

- 当日のセッション（CME の1日。米国中部時間17:00から）の約定量の累計を、価格ごとの横棒で表示する。スクロールしても変わらない。【確定】（2026-10-27 ユーザー決定）
- 棒はグレー、バリューエリア（出来高の70%帯）はオレンジ、POC（出来高が最大の価格）は白。【確定】
- POC の高さに白い点線、VAH・VAL の高さにオレンジの点線。3本とも VP の右端から大口板列の左端まで伸ばす（ヒートマップと価格軸には引かない）。【確定】（2026-10-28 ユーザー決定）
- VAH〜VAL の間は、VP の領域の背景を薄いオレンジで塗る（棒より下）。【確定】（2026-10-28 ユーザー決定）
- 縮小したときは、1画素の行に入る価格の出来高を合計する。【確定】
- 集計はサーバーで行う。詳細は SPEC 7.4 節。

### 3.7 デルタヒストグラム（下段）

- 見出しは「Delta」。区間ごとの買い約定−売り約定。＋は白で上向き、−は紫で下向き。【確定】
- 1本の秒数は、画面の拡大率に合わせて、1秒・5秒・15秒・60秒・300秒から自動で選ぶ（1本の幅が3px以上になる最小のもの）。【確定】（2026-10-27 ユーザー決定）
- 高さの基準は、見えている区間の |デルタ| の最大。【確定】
- 詳細は SPEC 7.5 節。

### 3.8 時間軸

- 最下部に時刻ラベル（hh:mm:ss）。【推定】
- 表示する時刻のタイムゾーン：日本時間と米国中部時間（America/Chicago、夏時間に追従）を切り替えられる。初期値は日本時間。切り替えは設定画面で行う（Phase 9）。【確定】
- 切り替えるのは表示だけ。集計の区切り（列、デルタの区間、VP のセッション）は取引所時刻のままで変わらない。【確定】（2026-10-28）

### 3.9 設定画面【確定】（2026-10-28 ユーザー決定、Phase 9）

- ツールバーの設定アイコンを押すと、画面中央に開く。チャートの上に重なる。
- 大きさ：幅は `min(480px, 画面の幅 − 32px)`。高さは中身に合わせ、画面に収まらなければ中だけスクロールする。
- 開いている間、後ろのチャートは暗く（黒の不透明度0.5を重ねる）するが、更新は止めない。チャートの操作は受け付けない。
- 開いたときに、サーバーから最新の設定を読み直して入力欄に入れる（ほかの端末で変えた値を上書きしないため）。
- 項目は20個（SPEC 9 節「設定」）。見出しごとにまとめて並べる。項目が多いので、見出しごとに開いたり閉じたりできるようにし、最初はすべて開いておく（開閉の状態はその端末のブラウザにだけ覚える）：

| 見出し | 項目 | 入力 |
| --- | --- | --- |
| ヒートマップ | 上限の決め方 | 「自動（上位 %）」「枚数」の2択 |
| ヒートマップ | 上限：上位 % ／ 上限：枚数 | 数値／整数（選んだ決め方のほうだけを出す） |
| ヒートマップ | 下限の決め方 | 「なし」「下位 %」「枚数」の3択 |
| ヒートマップ | 下限：下位 % ／ 下限：枚数 | 数値／整数（選んだ決め方のほうだけを出す。「なし」なら出さない） |
| ヒートマップ | コントラスト（1 = 直線） | 数値 |
| 約定バブル | 閾値（枚） | 整数 |
| 大口板 | 閾値（上位 %） | 数値 |
| 大口板 | 継続時間（秒） | 整数 |
| 時間軸 | 時刻の表示 | 「日本時間」「米国中部時間」の2択 |
| 約定バブル | 大きさ（倍率） | 数値 |
| 現在の板 | 棒の最大の長さ（ヒートマップの幅の %） | 整数 |
| 現在の板 | 棒の不透明度 | 数値 |
| 約定バブル | 表示の種類 | 「出来高」「デルタ」「売買分割」の3択 |
| 約定バブル | 色の付け方 | 「多いほうの色」「割合で混ぜる」の2択（「出来高」のときだけ出す） |
| 約定バブル | 大きさの伸び方 | 「平方根」「直線」「対数」の3択 |
| 約定バブル | 不透明度 | 数値 |
| 約定バブル | 時間のまとめ方 | 「1秒」「5秒」「15秒」「60秒」「自動」の5択 |
| 約定バブル | 価格のまとめ方 | 「自動」か、ティック数（整数） |

- 入力欄の横に、受け付ける範囲と初期値を小さく出す。範囲の外や数字でないときは、その欄の下に赤字で理由を出し、「保存」を押せなくする。
- ボタン：「保存」「初期値に戻す」。
  - 「保存」：サーバーに保存し、成功したら画面を閉じて、その場で反映する（再読み込みしない）。失敗したら画面を閉じずに理由を出し、反映しない。
  - 「初期値に戻す」：入力欄を初期値にするだけ。保存は「保存」を押したとき。
- 閉じ方：右上の×、画面外の暗い部分を押す、PC は Esc キー。保存せずに閉じたら、入力した変更は捨てる。
- URL の指定（`?bubbleMin=` など）でそのタブだけ上書きしている項目は、その欄に「URL の指定で上書き中」と出す。
- 反映で描き直すのは、その値を使う層だけ：
  - ヒートマップの上限・下限・コントラスト：ヒートマップと今の板の色の帯（上限は現在の板の棒の長さにも使う）
  - バブルの閾値・大きさ・表示の種類・色の付け方・大きさの伸び方・不透明度・まとめ方：約定バブル
  - 棒の長さ・不透明度：現在の板の棒
  - 大口板の閾値・継続時間：大口板列（手元の列から追跡を作り直す）
  - 時刻の表示：時間軸（ほかに時刻を出している所があればそこも）
  - VP とデルタは変わらない。
- 色・文字：背景 `#111111`、枠 1px `#333333`、文字 `#d9d9d9`、見出し `#ffffff`、エラー `#ff5c5c`、「保存」ボタンは `#8a3cff` に白字。

### 3.10 価格軸（ヒートマップと大口板列の間）

- 価格の目盛りを縦に並べる。価格はティック整数×0.25 で表示する。拡大率に合わせて目盛りの間隔を変える。【確定】
- 上下ドラッグで価格方向のズームをする操作は、この列で受ける（5 節）。【確定】
- 下段（デルタヒストグラムと同じ高さ）は、デルタの目盛り（+最大値 / 0 / −最大値の数値）と、今の1本の秒数を出す（Phase 8）。【確定】
- デルタの目盛りの文字：数値は 12 CSS px・`#d9d9d9`、+最大値は上端、0 は中央、−最大値は下端。今の1本の秒数（例「15s」）は 11 CSS px・`#8a8a8a` で、0 と同じ行の右寄せ。数値と重ならないようにする。【確定】（2026-10-28 ユーザー決定。それまでの文字は小さくて読みにくかった）
- 現在値のラベル：白地に黒字で、価格を出す（Phase 4）。【確定】
- POC・VAH・VAL のラベル：その高さに価格を出す。POC は `#333333` の地に白字、VAH・VAL は `#f5a623` の地に黒字。文字は 11 CSS px。現在値のラベルと重なったときは現在値のラベルを上に描く。POC・VAH・VAL どうしが重なったときは POC を上に。【確定】（2026-10-28）

## 5. 操作

- チャートの移動と拡大縮小は、指・マウスでチャートを直接触って行う。アイコンでは行わない。【確定】
- 機能の呼び出し（設定・表示リセット）は、左端のツールバーのアイコンで行う。【確定】
- 具体的な割り当て：【案】
  - マウスホイール：時間方向のズーム
  - ドラッグ：時間方向のスクロール
  - 価格軸の上下ドラッグ：価格方向のズーム
  - タッチ：ピンチでズーム、1本指でスクロール
  - ダブルクリック／ダブルタップ：
    - チャート本体（ヒートマップ・大口板列・VP）の上：現在値に戻る（ツールバーの表示リセットと同じ動き）
    - 価格軸の列の上：価格の自動モードにする（下）
    - 時間軸の上：時間だけを戻す（下）
- 価格の自動モード：見えている時間の範囲の約定の最高値〜最安値が、価格方向の高さの 80% に収まるように拡大率と位置を合わせる（上下に10%ずつ余白）。最小の幅は20ティック。見えている範囲に約定がなければ、現在値を中央にして初期の拡大率にする。自動モードのあいだは、新しい約定やスクロールで範囲が変わるたびに合わせ直す（1秒に1回まで）。自分で価格方向に拡大縮小・移動したら、自動モードを止める。価格軸の列の上端に小さく「AUTO」と出す。TradingView の自動スケールと同じ考え方。【確定】（2026-10-28 ユーザー決定）
- 時間軸のダブルクリック：時間方向の拡大率だけを初期値に戻し、ライブでは追いかけを再開して最新の列を右端から20%手前に置く。リプレイでは再生位置に戻す。価格方向は変えない。【確定】（2026-10-28 ユーザー決定）
- 表示リセット（ツールバーのアイコンとダブルクリック／ダブルタップで同じ動き）：時間・価格の拡大率を初期値に戻し、ライブでは追いかけを再開して最新の列を右端から20%手前に置き、現在値を価格の中央にする。リプレイでは再生位置に戻す。設定の値は変えない。【確定】（2026-10-28）
