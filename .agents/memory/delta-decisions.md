---
name: デルタの不足区間と見た目
description: 正本にないデルタ棒の取得不足時の扱いと、ユーザー承認済みの見た目。
---

画面端に一部だけ見える棒も区間全体で集計する。保持境界や履歴取得中などで区間全体がそろわない棒は描かない。進行中の最新区間は、受信済みの約定で更新する。

**Why:** ユーザーが、不完全な過去の棒を確定値に見せない提案を承認した。

**How to apply:** 約定0件の区間と未取得区間を区別する。範囲の完了前・中断・保持範囲外を、完全取得済みとして扱わない。

棒は区間幅いっぱいで隙間なし。中央線は既存枠線色 `#252431`、1 CSS px。目盛りは既存軸と同じ書体・色を使う。

**Why:** ユーザーが、仕様にない見た目の提案を承認した。

**How to apply:** 正本の差し替えなしに承認を得た補足として、報告にも記載する。

ライブ受信の約定保持上限は、追尾中か過去へスクロール中かにかかわらず最新受信約定まで進める。2時間の上限は維持する。リプレイの再生位置までという動作は変更しない。

**Why:** ユーザーが、最新確定列より先の約定を捨てる問題を「Phase 4からの不具合」として修正するよう指定した。追尾中だけの修正ではなく、過去閲覧中にも約定を残すことを明示した。

**How to apply:** ライブとリプレイ、板と約定の保持基準を混同しない。ライブで最新2時間より古い表示範囲の約定が不足する場合も、2時間制限を無断で拡張しない。
