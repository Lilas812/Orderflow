---
name: Volume Profileの採用Value Area契約
description: 実装前にユーザーが確定した70%・隣接tick・同量両側拡張の規則
---

Value Areaは70%。POCから連続した整数tick範囲を拡張し、直近の上下隣接tickの出来高が多い側を優先する。同量なら両側を含める。ゼロ出来高tickも通過する。数量・70%判定はbigint整数演算を使用し、総出来高0ではVAH/VALともnull。

**Why:** ユーザーが採用仕様として明示した。隣接する約定価格へ直接飛ぶ方式では、途中のゼロtickの両側拡張を省略して異なる結果になることがある。

**How to apply:** 実装は別途承認を受ける。Trade受理時の再計算や全Trade再走査をせず、既存VPの読み取り経路へ追加する。ゼロ区間の高速化を提案する場合も、1tickずつの規則と一致することを示す。
