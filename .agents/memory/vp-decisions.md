name: VPの追加指定と正本への例外
description: Phase 7で正本より優先するとユーザーが明示承認したセッション・POC・被覆・縮小表示の扱い
---

VPについて、ユーザーは次の4点を指定した。

1. セッションはChicago17:00から翌日17:00直前まで。16:00〜17:00に約定があれば、終わる側のセッションに含める。
2. 最大出来高の価格が複数ある場合、POCは高い価格。
3. ファイルの存在ではなくPhase 2aの取得済み区間の記録を使い、不足窓だけを半開区間で補完する。通信で3回失敗した窓はログとHTTP状態に欠けとして出し、その窓を除いたVPをloading:falseにする。
4. 縮小して画素行の出来高を合計した場合、可視行の最大合計を棒の全幅基準にする。縮小しない場合はPOC基準と同じ。

**Why:** 2026-10-27、正本の「翌日16:00終了」と指定1の矛盾を報告して停止した後、ユーザーが「今回の4点を優先する」と明示承認した。正本本文は追加変更せず、報告書の「仕様にない値」に一覧を記すよう指示された。

**How to apply:** VPに関するこの承認を別の板描画規則に広げない。新しいユーザー指示・正本改訂があれば確認し、旧仕様の記載だけを理由に承認済みのVP境界や縮小方法へ戻さない。ファイルが一部だけ存在する不足窓の保存は、既存の部分行に同じ期間の履歴を単純追記して重複させない。
