## 2. 新UIのワイヤーフレーム [P]

推奨デザイン基準: **1920×1080論理CSS px**。ズーム/OSスケール別でも崩れないCSS Grid設計。

│  Brand   [NQ 2026-12 ▼]    MOCK ●   [LIVE/HISTORY]          最新  設定  診断         │ 52
├───────────────────────────────────────────────────────────────────────────────────┤
│  Pointer  Pan  Zoom  Crosshair     30m ▼      Heatmap ☑ Bubbles ☑ Delta ☑         │ 40
├───────────────────────────────────────────────┬────────┬──────────────────────────┤
│                                               │ PRICE  │ RIGHT: Ladder (Bid/Ask)  │
│   Heatmap + Price Line + Delta Bubbles        │ AXIS   │ Ask Qty | Price | Bid Qty │
│   historical time across x, price across y    │  72px  │ 300px [P]                 │
│                                               │        │ (profile/order reserved) │
├───────────────────────────────────────────────┼────────┼──────────────────────────┤
│   Delta Histogram / 0-line                   │        │ Right panel keeps ladder │ 126
├───────────────────────────────────────────────┴────────┴──────────────────────────┤

板の色計算は`quantity -> normalizedIntensity -> palette -> RGBA`。データ計算ロジック内にRGB文字列を置かない。低輝度は背景へ連続的に近づける。ガンマやコントラスト調整は色出力側のみ。[P]フォントはWindowsのSegoe UI + 数値等幅（Consolas/システム代替）。外部の商用フォントを無断同梱しない。

注意: 緑/紫は**正のデルタ/負のデルタ**と**Bid/Ask resting liquidity**の両方に用いるが、ツールチップと凡例には「約定 / 板」を必ず表示して混同させない。色覚アクセシビリティとしてアイコン/+/−/数値でも区別。

## 4. メインチャートの描画レイヤー・ピクセル整合

奥→手前のZ順 [C]: ①背景 ②セッション/欠損の帯 ③MBPヒートマップ ④罫線（必要に応じ半透明）⑤最終約定の価格線 ⑥約定バブル ⑦クロスヘア/ツールチップ。将来のラインオブジェクトは別レイヤー。

- D3などのDOMレイヤーで毎イベント再描画しない。WebGL2でヒートマップテクスチャ/タイルをGPU処理。目盛や設定はReact/DOMで描く。
- CSSピクセルとdevicePixelRatioを分ける。Viewport boundsは**CSSpx**で共有し、GPUはDPRを掛けてviewportを設定する。HUD/ホバーはCSSpx座標。
- 250msごとに「最後に確定した描画フレーム」を更新。受信スレッドはこの周期に依存しない。
- 価格線の幅 [P] 1.3 CSSpx、継続市場時間の最終約定を折れ線で連結。ただし**欠損/セッション境界にまたがる補間線を描かない**。
- 水平帯は過去の各バケットに残り、現在板の消失を過去に適用しない。ラダーの数字は現時点の板のみ。
- ヒートマップに`NO DATA`領域がある時は**不透明の色帯を描かない**。背景の斜線と小さな警告を表示。板0のセルは正常背景色。
- 描画欠落と市場データ欠損は異なるため、GPU context lost時は「RENDER ERROR」表示。

## 6. 価格ラダー [C]

- 3カラム `AskQty | Price | BidQty`、価格刻み = NQ 0.25、価格降順。
- ピクセル中心は `priceToY(tick)` と一致。単一行の高さはチャート価格スケール由来なので固定20pxとは限らず、過密時は間引き目盛でも**数量の価格紐付けをずらさない**。
- 現在のbest bid/askをそれぞれ線とラベルで強調。現在価格ラベルはlast trade、best bid/askとは混同しない。
- 一つの価格にBidとAskが両方存在するケース（異常板/クロス含む）をデータとして勝手に消去しない。監視警告を設ける。
- 表示現在量は板全体の整合性フラグがVALIDの時にのみ確定数値を表示。欠損なら灰色`—`。
- 右パネル上部に将来のVolume Profileタブ（グレーで無効）・注文パネル領域のプレースホルダ。**注文ボタンを動作するUIとして置かない**。

## 7. 約定バブル視覚仕様 [C/P]

- 時間2秒、価格2Tickのビン。中心 `x=(binStart+binEnd)/2`, `y=(lowest+highestTick)/2`（同値の場合、2Tick帯の幾何中心）で一意に決まる。
- 色: Delta正緑、負紫、0灰。未確定 opacity 0.45 [P]、確定 opacity 0.92 [P]、境界線0.8px [P]。
- 直径 [P] 最小8px、最大24px、基準量100枚 [P]（サイズ関数は `DATA_SPEC.md`）。設定で変えられる。
- `ALL`: フィルター後を全部表示（重なり可）。`STANDARD`: 同方向で近距離を表示だけ統合。`HIGH_COMPRESSION`: より広範囲の近接クラスタを統合。統合は数値を捏造せず、所属バブルID配列を保持。
- ホバー: 集計開始/終了、価格帯、買い、売り、合計、Delta、|Delta|/合計%、`PROVISIONAL/FINAL/REVISED/INCOMPLETE`、構成元の個数。統合クラスタは合計と内訳へ展開。
- 途中に方向が変われば即座に色が変化。ウォーターマークによるFINAL後に遅延訂正が来たらREVISED表示と改訂番号を提示。

## 8. Delta下段 [C]

- 同じ期間・zoomを用い、2秒ごとに分類済み約定の `Buy-Sell` を棒にする（初期案）。0線を常時表示、正は上に緑、負は下に紫。
- 未確定バケットは半透明。分類不明や欠損の場合はその棒を「不完全」とするか空白+NO DATAを表示。0の棒として描かない。
- Deltaバーへのホバーにbuy/sell/tradesCountと状態。Y軸はDeltaの最大絶対値で対称スケール [P]、必要に応じ固定スケール設定。
- メインとDelta間の境界ドラッグで縦サイズ変更可能 [P]。

## 9. 設定画面 / 値域 / 保存 [C]

歯車/右クリック → `Display Settings`。タブ：Heatmap / Bubbles / Price Line / Viewport / Data Status。右から開くモーダルではなく幅360–420pxのサイドドロワー [P]。**変更時プレビュー**、`適用して保存`と`キャンセル`を独立。

|---|---|---|---|
| Minimum Liquidity Volume | number / 50 | 0–5000 [P] スライダー+任意非負整数の数値入力（上限超値はスライダー最大を拡張） | 全可視・過去ヒートマップを再評価 |

| Min/Max Intensity | slider / 0.05,1.0 | 0..1, min<max | カラーマッピングのみ |
| Liquidity Contrast | slider / 1 | 0.25..4 [P] | カラーマッピング |
| Top Contrast | slider / 1 | 0.25..4 [P] | 高輝度の圧縮/強調 |
| Fixed Baseline | checkbox / ON [P] | トグル/基準保存 | 時点比較可能 |

## 10. データソースと障害の表示 [C]

| 表示 | 意味 | UIの必須応答 |
|---|---|---|
| `MOCK • Simulated` | 架空イベント | タイトル/チャート内ウォーターマーク、設定やスクリーンショットに識別が残る |
| `LIVE • Verified` | 契約・検証済みvendor | 最終到着時刻・最終取引所イベント時刻を並記 |
| `CONNECTING` | 接続準備 | 未取得データは`NO DATA` |
| `RESYNCING` | 差分喪失後に新snapshot待ち | ラダー不確定、ヒートマップにgap帯 |
| `STALE` | 更新途絶・心拍不整合 | 何秒前の板か表示し自動LIVEのように見せない |
| `NO DATA: L2` | depthなし/断絶 | depthだけ斜線; tradeは独立に有効可 |
| `NO DATA: TRADES` | tradesなし/断絶 | bubble/Deltaだけ無効; depthは独立に有効可 |
| `NO DATA: L1` | best bid/askなし | L1テキストのみ無効。復元済L2 bestをL1と混同しない |
| `STORAGE ERROR` | ディスク不足/書き込み失敗 | 保存が不完全と明示、無音継続禁止 |

## 11. レスポンシブ・アクセシビリティ・UI合格試験

- ズーム 100/125/150%、解像度 1280×720 / 1920×1080 / 2560×1440を手動確認。細い線のにじみ/価格軸ずれがない。
- キーボードTabで設定項目に到達、ラベル・単位とフォーカスリング、ARIA説明、フォーカス閉じ込め/戻し。
- 色だけで買い/売り/欠損を表現せず、符号、ラベル、斜線パターンを併用。
- ウィンドウリサイズ直後に価格ライン/ラダー/バブルが同一価格Yに揃う（許容1 CSSpx [P]）。
- LIVE→左ドラッグ→HISTORY→新データ受信後も位置が動かない→最新押下でLIVEへ。価格軸だけMANUALは独立維持。
- フィルターを50→0→50と戻したとき、元のタイル値が再現される。色変更で板数量やDeltaが変化しない。
- 画像一致率を合否指標としない。UI要素と計算表示の一致をユニットテストと手動手順で確認する。
