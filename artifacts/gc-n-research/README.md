# GCZ6 N約定リサーチ

## レンジバー俯瞰（開発専用）

`/gc-n-research/range-bars` はNQZ26/GCZ26の購入原約定から作る独立研究画面です。
既存の日別・期間俯瞰はそのまま残ります。足・CT17時境界・終了日ラベル・coverage欠け・
部分足・同時刻の安定順序・反転候補・マーク保存の定義は
[RANGE_BARS.md](RANGE_BARS.md) を参照してください。

NQ初期40ticks＝10ポイント、GC初期20ticks＝2ドル。補助線は初期OFF。
天底は本人のhindsightであり、候補やマークを売買シグナル・客観的な正解とは扱いません。
マークと基準メモは新しい研究専用サーバー保存で共有し、v1保存/APIは使いません。
通常の本番ビルドではpublicDirを無効にし、新旧の購入JSONをコピーしません。
新画面のコードと導線もDEV限定です。公開・再Publishは行っていません。

前セッション(実取引セッション)の **N(不明アグレッサー)約定のみ** の価格プロファイル(左)と、
選択セッションの実1分足(右)を **同一の価格変換・同一のy範囲** で表示する個人用リサーチチャート。
売買シグナル・自動ラベル・バックテストはありません。

## データ
- `public/research-data/index.json` と各セッションファイル(親工程が生成、静的fetch)。
- セッション = CT 17:00 → 翌17:00、ラベルは終了日。価格はtick整数 × 0.1。
- ピンクの集中価格は **前セッションのプロファイルのみ** から選択(当日データは一切使わない)。

## 操作
| 操作 | 内容 |
|---|---|
| ‹ / › ・日付欄 | 利用可能なセッション間を移動。存在しない日付は「利用できません」と表示し、自動で別日に置換しない |
| 上位N本 (既定3) | 数量上位のN価格(同数は高い価格を先にする。既存調査と同じ) |
| 最小数量 (既定1) | この数量未満の価格を除外 |
| 価格バケット (既定1tick) | 前プロファイルをtick単位でまとめて選択 |
| CT / JST | 時間軸・ツールチップの時刻表示 |
| ホイール(右ペイン) | 時間ズーム(カーソル基準) |
| ホイール(左ペイン/価格軸)・Shift+ホイール | 価格ズーム(両ペイン共通) |
| ドラッグ | 右: 時間+価格パン / 左: 価格パン |
| ボタン | 時間±・左右、価格±・上下、フィット、リセット |
| キーボード(チャートにフォーカス) | ←→ 時間パン、↑↓ 価格パン、+/− 時間ズーム、R リセット |

最初はセッション全体を表示します。拡大すると個々の1分足を詳しく確認できます。
約定のない分は空白(ギャップ)のまま表示され、フラット足は生成しません。

## データの再生成と検査
プロジェクト直下から実行します。原本は読み取り専用で、既存製品へ接続しません。

```
python artifacts/gc-n-research/scripts/export_research.py
python -m unittest discover -s artifacts/gc-n-research/scripts -p 'test_*.py' -v
node --experimental-strip-types --test artifacts/gc-n-research/scripts/research.test.mjs
pnpm --filter @workspace/gc-n-research run typecheck
PORT=20373 BASE_PATH=/gc-n-research/ pnpm --filter @workspace/gc-n-research run build
```

生成JSONはGit対象外の派生キャッシュです。別環境では既存の購入データを配置して再生成してください。
配信は研究用ページの独立したプレビューだけで、公開・本番データ反映はしていません。

## 期間俯瞰 (/overview)

`/gc-n-research/overview` — 過去のN集中価格が月内で再訪されたかを目視確認するページ(売買シグナルではありません)。

- 期間: 暦月(既定・index最新月を全体フィット)/ 基準セッションまでの観測1/3/5/10/20セッション / 任意の開始・終了(CT)。データの無い区間は灰色、部分セッションは黄色で表示。
- ローソク足 1分/5分。左プロファイルは同じ価格軸(単日/5/10/20/表示期間、回顧のみでラインは生成しない)。
- ライン起点: 前日/5/10/20/表示期間。上位N本(3)・最小数量(1)・バケットtick(1)・保持1/3/5/全(全)。
- 初期起点は「表示期間」。起点フィルタは各表示セッションの過去N由来を候補に追加し、選ばれた古いラインは別指定の保持期間まで残す（起点フィルタで寿命を短縮しない）。
- 保持「全」も購入済みの観測末端まで。終了していない末尾の部分セッションから、終了後ラインを先取りして生成しない。
- 記述ルール: 反応幅tick(20)・観測窓5/15/30分(15)・許容tick(1)。
- ラインは起点の有効開始から終了まで描画。古い起点ほど淡く、太さは同価格で既に形成済みかつ同時有効な本数。破線=sourcePartial/historyShort。
- ライン・一覧行クリックで詳細(起点、N数量/件数、有効期間、フラグ、接触イベント)。同価格帯の別起点は切替ボタンで選択。
- 操作: ホイール=時間ズーム、Shift+ホイール/右軸ドラッグ=価格ズーム、ドラッグ=移動、ボタン、ダブルクリック=フィット。CT/JST切替。
- 日別: カレンダー/リスト。N lot、N/(A+B)、N/(A+B+N)、主要価格、後続接触数。
- 全23セッションファイルを読み込み、1件でも失敗した場合は部分結果を表示せずエラーを表示。
