# GCZ6 N集中価格・期間俯瞰の実装報告

## 実施内容

既存研究アプリに `/gc-n-research/overview` を追加。従来の日別ビュー `/gc-n-research/` は保持。
GCZ6の購入済み約定だけで月全体・複数セッションの価格推移と、その前に形成されたN集中価格を観察する。
売買シグナル・統計的優位性の判定・条件探索は実装していない。

## 変更ファイル

- `scripts/export_research.py`：既存日別JSONの意味を変えず、当該セッション自身の`ownProfile`と
  `availableStartMs/availableEndMs`を追加。購入原本・元SQLiteは読み取り専用。
- `src/lib/overview.ts`：
  - `ctSessionBounds`：CT17:00とDSTに対応したセッション境界。
  - `buildOverview`：由来ごとの形成・有効期間、Nプロファイル合算、両比率、日別一覧。
  - `observeLine`：接近側、連続接触・観測窓重複除外、反応・突破・不明・不足の分離。
  - `aggregateCandles`：実1分足だけから5分OHLCVを生成。空の時間帯は補完しない。
  - `overlapSegments`：各時点で形成済み・有効な同価格の本数だけを装飾へ使う。
- `src/hooks/use-overview.ts`：既存日別クエリとキャッシュを共有し、収録23ファイルを読み込む。
  取得失敗・形式不整合時は部分結果を完成扱いせず再取得を案内。
- `src/components/overview-chart.tsx`：共通価格軸、月全体フィット、ラインクリック、時間・価格操作。
- `src/components/overview-panels.tsx`：由来別の詳細・タッチ履歴、カレンダー／一覧、両比率。
- `src/pages/overview.tsx`：期間・集計・保持・判定ルールの操作と明示的な入力エラー表示。
- `src/App.tsx`：追加ルートのみ。
- `src/pages/research.tsx`：期間俯瞰へのリンクのみ。日別描画・既存集計は変更しない。
- `scripts/overview.test.mjs`、`scripts/overview_browser_check.mjs`：隔離確認。
- `README.md`、本書：操作・検証記録。

## 確認手順・操作方法

1. 研究ページの「期間俯瞰」、または `/gc-n-research/overview` を開く。
2. 最初は2026年10月の暦月全体、5分足、表示期間由来の上位3価格、有効期間「全」。
3. 「ライン起点」で各表示セッションの前日／過去5・10・20／表示期間由来を選択。
   選ばれたラインの寿命は別の「保持」設定で決まり、起点フィルタだけで古い線を消さない。
4. ラインまたは右の一覧行をクリックすると、由来日・N枚数／件数・有効期間・品質・
   接近側・その後のタッチ履歴を確認できる。近接する複数ラインは詳細の切替ボタンで選択。
5. ホイール／時間ボタンで拡大・左右移動。ドラッグで時間・価格移動、
   Shift＋ホイールまたは価格軸操作で価格調整。「フィット」で月全体へ戻る。
6. 左は単一セッション・5／10／20セッション・表示期間のN合算。基準日を選択可能。
   これは回顧用で、合算結果から過去のラインを選び直さない。
7. 下のカレンダー／一覧でN枚数、従来比N/(A+B)、全体比N/(A+B+N)、主要価格、
   表示期間内のライン別延べ接触数を確認。日付クリックは左の単日プロファイルへ反映。
8. 反応幅20ティック、観測窓15分、許容幅±1ティックが初期値。いずれも変更可能。
   反応幅≦許容幅などの入力は明示的に無効とし、勝手に値を変更しない。

## 未来参照と簡易集計の定義

- 由来セッションが終了した後、次の実在セッション開始以降だけラインを描画する。
- 冒頭を欠く由来は品質付きで扱う。終了まで収録できていない最終セッションから、
  終了後ラインを先取りして生成しない。保持「全」も収録末端で打ち切る。
- 上位価格の選択はその由来日のN数量だけ。後日の価格・合算プロファイルは選択に使わない。
- 高安が許容帯に重なる一連の足を1接触とし、いったん帯を離れてから新規接触候補とする。
- 1ラインにつき、採用したタッチから判定時間全体を確保する。早く反応が確定しても、
  同じ観測窓内の再接触は追加カウントしない。別由来のラインは別の研究対象として扱う。
- 前足終値とタッチ足始値で接近側が確認できなければ「判定不能」。
- タッチ足での極値がタッチ前か後か不明な場合、終値等で順序を証明できなければ
  後続足だけを見て反応へ振り替えない。同じ足で両閾値へ到達した場合も「判定不能」。
- 接近側へ所定幅戻れば反応、反対側へ進めば突破。確認済み突破後の別接触を再テストとする。
- 未収録・有効期間末端で判定時間が不足する場合は、無反応ではなく「観測不足」。
- 日別接触数は各ラインの延べ数。同じ時刻に別ラインへ接触したことを、独立した
  市場イベントの総数や統計的な独立標本数として扱わない。

## 仕様との差分・未解決

- 既存製品・仕様正本・原本・本番・公開先の変更なし。研究用の派生JSONに項目追加のみ。
- 購入範囲はUTC `[2026-09-30 00:00, 2026-10-30 00:00)`。10/30セッションは
  CT10/29 17:00〜19:00の2時間だけ。10/31セッションは未収録。月の枠があることを
  月末までの実データがそろうこととは説明していない。
- 灰色は未収録・休場等。取引所の休日カレンダー照合による休場／供給欠損の断定はしない。
- OHLCで分からない約定順は判定不能のまま。実約定順に照合して確定分類したものではない。
- 実機Safariのタッチ操作は未確認。売買の有効性・反発率の再検証は対象外。
- 研究ページ配信用workflowは残す。検証用の追加サーバー・上流接続は起動していない。
